# KipClub — исходники бренда

* `source/` — комплект от дизайнера (фон #B83B29, знак #FFF8F4).
* `android/res/` — готовые ресурсы иконки Android (adaptive + monochrome + legacy mipmap); `android/scripts/patch-android.mjs` копирует все `ic_launcher*` в сгенерированный проект при каждой сборке.
* Веб-иконки лежат в `frontend/icons/` (+ `frontend/favicon.ico`).
