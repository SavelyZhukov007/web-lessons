KipClub — комплект иконок (вариант №5 «Маршруты»)

ФОН: #B83B29 (RGB 184, 59, 41)
ЗНАК: #FFF8F4 (RGB 255, 248, 244)

ОСНОВНЫЕ ФАЙЛЫ
- kipclub-ios-pwa-1024.png — 1024x1024, RGB, без прозрачности и заранее скруглённых углов; подходит для iOS/PWA
- kipclub-android-foreground-1024.png — 1024x1024, RGBA, белый знак и прозрачный фон, знак в центральных ~50% площади по ширине/высоте (проверен для круговой маски Android)
- kipclub-android-background-1024.png — 1024x1024, однотонный фон
- kipclub-android-monochrome-1024.png — 1024x1024, белый одноцветный знак на прозрачном фоне для тематических иконок Android 13+

ДОПОЛНИТЕЛЬНО
- kipclub-mark-red-transparent-1024.png — красный знак без фона для использования на светлой подложке
- apple-touch-icon-180.png, pwa-icon-192.png, pwa-icon-512.png — готовые размеры
- favicon-16.png, favicon-32.png, favicon-48.png, favicon.ico — маленькие размеры
- *.svg — масштабируемые векторные версии знака и основной иконки

ПРИМЕЧАНИЯ
- В Android adaptive icon назначайте foreground и background отдельно. Фон однотонный: #B83B29.
- В Android monochrome цвет готового силуэта будет выбираться системой по маске прозрачности.
- Все знаки построены по выбранной концепции №5 из ранее созданного эскиза. Геометрия перенесена из исходного изображения, это чистовой технический экспорт, а не ручной утверждённый векторный логотип.
