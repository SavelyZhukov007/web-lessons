Как установить APK

  1. Скачайте файл

    Нажмите «Скачать APK». Если браузер предупредит о типе файла, выберите «Всё равно скачать».

  2. Разрешите установку

    Откройте скачанный файл. Android попросит разрешение: Настройки → «Разрешить из этого источника» для вашего браузера или «Файлов». Разрешение нужно дать один раз.

  3. Установите и откройте

    Нажмите «Установить», затем «Открыть». Обновление ставится так же — поверх, данные сохранятся.

Где найти «неизвестные источники» на моём телефоне
  • Android 8 и новее: Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → ваш браузер → Разрешить.
  • Samsung: Настройки → Приложения → ⋮ → Особые права доступа → Установка неизвестных приложений.
  • Xiaomi / Redmi / POCO: Настройки → Защита конфиденциальности → Специальные разрешения → Установка неизвестных приложений.
  • Huawei / Honor: Настройки → Безопасность → Дополнительные настройки → Установка приложений из внешних источников.
  • Android 7 и старше: Настройки → Безопасность → «Неизвестные источники».

После установки разрешение можно снова выключить — приложение продолжит работать.
