# KipClub 1.9.021 / Android code 38 — итоговый этап

## Реализовано
- Доработаны уже существующие Android-виджеты «Следующее занятие»/«Сегодня»: объединение избранных кружков, руководителей и аудиторий; несколько кабинетов/руководителей; дедупликация перенесённого события; «сейчас»/15 минут/прогресс и московское время сохранённого снимка. Избранное виджетов не расширяет подписки на уведомления.
- Добавление виджетов из настоящих нативных настроек. При отсутствии виджетов будильник отменяется; с виджетами только неточные non-wakeup перерисовки по границам и раз в минуту около занятия, без нового сетевого polling. Ограничения Doze/лаунчера сохраняются.
- Ссылка «3D-тур КИПФИН» в подробностях занятия и настройках web/PWA/Android: https://tour.panoee.net/65e08e217a73f2feff4db099/65e08e717a73f212cb4db0ac . Официальная https://kip.fa.ru/ ссылается на этот тур; URL отвечает HTTP 200 (Panoee). Своей карты/маршрутов нет. Настоящий iOS widget не добавлен: для PWA это не тривиальная возможность.
- Android-лента сохраняет один transform spring, но 30 визуальных элементов скрыты от AX и заменены шестью неподвижными семантическими кнопками с названиями дат, занятостью, «сегодня»/«выбрано», клавиатурой и roving focus. TalkBack touch exploration включает reduced motion и отключает content-visibility, чтобы не прятать содержимое от AT.
- На физическом Tecno обнаружен дополнительный touch-дефект: глобальный ripple присваивал CSS-absolute кнопке inline position:relative в pointerdown, удваивал высоту ленты и уводил цель до click. Для семантических hit-targets ripple пропускается; прочие CSS-positioned кнопки больше не перепозиционируются. Программный перенос фокуса выполняется только для клавиатуры/AT, не для обычного touch. Также старый глобальный anti-double-tap больше не проглатывает быстрые последовательные активации интерактивных контролов. Регрессии проверяют настоящий tap и неизменность высоты, не только программный goto.
- Согласие на анонимную аналитику выключено по умолчанию. Только ограниченные счётчики действий/корзины числа результатов и подписи технических ошибок (тип, статический JS/CSS basename, строка, версия); без текста поиска, message/stack, аккаунта/установки/постоянного ID в payload и БД аналитики. credentials:omit; очередь/ретраи ограничены, случайный ID только на batch для SQL-дедупликации, отмена согласия сбрасывает/прерывает неотправленное. Хранение 30 московских дней, удаление также без новых поступлений. В админке явно обозначено: это события, не уникальные люди или связанная персональная воронка; APK click не доказывает установку, iOS appinstalled недоступен.
- Миграция 0017, frozen DDL; upgrade/downgrade проверены. Каждый backup теперь действительно восстанавливается во вторую временную SQLite-БД через Online Backup API, сверяет integrity, FK, ревизию и все таблицы/число строк. Живая БД не подменяется, workers/push не стартуют, токены не отзываются. Ошибка запрещает ротацию старых хороших копий. Старые ревизии можно проверить изолированно и увидеть несовпадение head/таблиц, повреждение даёт понятную CLI-ошибку.
- На TEST не было ежедневного backup ни в systemd, ни в user/root cron. Добавлены отдельные Docker service/timer: 03:30–03:33 МСК, Persistent=true, keep14, intrinsic restore-check. Явный installer не перезаписывает отличающийся операторский unit и не меняет env/compose/secrets. Продакшену он автоматически не ставится.
- Privacy switch имеет семантическую 44px tap-зону и центрированную контрастную дорожку. WCAG AA fallback-цветов Android widgets и Today проверяются тестами; штатные Material You цвета предоставляет ОС. Настройки подключены и к web/PWA dialog, и к отдельному нативному экрану, а не только к одному из них.
