## Статус и датированные материалы

- [PROD_STATUS](PROD_STATUS.md) содержит историческую инвентаризацию, а не автоматически обновляемый статус production.
- Файлы с номером релиза или датой (`*19017*`, `*19018*`, `*19019*`, `*19020*`, `*19021*`, `RELEASE_*`, `final-release-*`) — зафиксированные отчёты и планы на момент создания. Их тестовые результаты и решения не следует трактовать как результаты текущей сборки.
- `NEXT_STAGE_TASKS.md`, `FRONTEND_TASKS_7_12.md`, `UX_REPORT.md` и QA-отчёты — материалы конкретных этапов; сверяйте описанное поведение с действующим кодом и актуальными контрактами.
