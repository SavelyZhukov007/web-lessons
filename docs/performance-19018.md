# KipClub 1.9.018 — запуск, загрузка и кэш

## Изменения

- Сохранённая публичная нефильтрованная неделя показывается раньше фоновой сети. Android использует атомарный файловый кэш в noBackupFilesDir; PWA/веб — IndexedDB. До 12 недель, TTL 48 ч, разделение по origin, валидация/защита от гонок и повреждения; настройки и авторизация туда не попадают.
- Фоновая предзагрузка соседних недель отменяется при смене контекста/скрытии страницы; учитываются saveData, 2G и энергосбережение. Существующий уникальный WorkManager обновляет тот же нативный кэш.
- Настройки/поисковый UI загружаются при обращении; индекс строится отменяемыми idle-порциями. Админка и печать остаются отдельными ленивыми entry points.
- Один GolosText UI subset с preload: 49 420 байт вместо 52 628; исходный шрифт сохранён для воспроизводимости, лишний TTF не попадает в сборку. SVG-иконки переиспользуют локальные symbol/use без внешних Safari-запросов.
- Статические файлы образуют content-versioned граф /assets/<hash>/. Только такие URL получают годовой immutable; HTML и mutable metadata — no-cache. SW ограничивает параллельный precache и хранит текущую/предыдущую оболочки. Активация обновления не перезагружает открытый документ и не сбрасывает форму; новый код применяется при следующей навигации. Учтён Vary: Origin у module/font запросов при offline precache.
- AndroidX WebKit background-capable prewarm без второго скрытого WebView, с fallback и уважением power saver. Нативный splash отпускается по первым committed pixels (а не ждёт JS rAF за блокировкой pre-draw); искусственное ожидание JS splash убрано, прогресс обслуживает одна rAF-цепочка.
- R8/shrinkResources, локальные assets и SplashScreen сохранены; добавлен небольшой нативный Baseline Profile и ProfileInstaller. Это исходный профиль нативного старта, не обещание полного Macrobenchmark-покрытия всех WebView-сценариев.
- Для standalone PWA persist() вызывается best effort после жеста пользователя: iOS всё равно может очистить хранилище. Существующие safe-area/защита крайних 24px от перехвата системного swipe сохранены. modal-scroll-lock.js не изменялся; восстановление scrollY проверено браузерным тестом.
