# Ручная проверка админки

Актуальный подробный список сценариев находится в [qa-checklist.md](qa-checklist.md), раздел «Админка». Этот файл — короткий вход для ручного smoke-теста; старые отчёты и тестовые команды не следует считать инструкцией для текущего кода.

## Подготовка

1. Запустите проект по [README.md](../README.md) на отдельной тестовой базе.
2. Создайте тестового администратора командой `python server.py admin create admin`; пароль вводится в консоли.
3. Откройте `http://127.0.0.1:8000/admin/login.html`.
4. Не используйте production-базу для тестовых изменений.

## Короткий smoke-тест

- Вход, выход, неверный пароль и ограничение повторных попыток.
- CRUD кружка, занятия и справочников; изменение статуса кружка.
- Создание периода и занятия с повтором; проверка даты вне периода и неучебного дня.
- Конфликт аудитории/руководителя, отмена и перенос занятия.
- Импорт: предпросмотр, подтверждение публикации и проверка целостности при ошибке.
- Предпросмотр массового действия и отмена поддерживаемой правки из журнала.
- Экспорт расписания; немедленная и запланированная рассылка.

Для каждого прохода зафиксируйте версию приложения, браузер/устройство, тестовые данные и результат. Политика конфликта, API и ограничения расписания описаны в [api-contract.md](api-contract.md) и [schedule-v2-contract.md](schedule-v2-contract.md).
