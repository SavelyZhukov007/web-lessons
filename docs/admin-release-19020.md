# KipClub 1.9.020 — этап 4: административные инструменты

Релиз 1.9.020, Android code 37. Только main и TEST; PROD не выкатывается.

## Сделано
- Журнал изменений расписания, постоянная полоса «Отменить», Ctrl/⌘ K (включая русскую раскладку). Откат на уровне строк, проверка ревизий/ABA, последующих правок и зависимых рассылок. Исходные данные и запись журнала коммитятся одной транзакцией, SQLite резервируется до before-image. При ошибке журнала исходная правка не сохраняется. Уже отправленные уведомления не отзываются.
- Массовая отмена выбранных занятий за диапазон (включая каникулы), удаление регулярных занятий: точный предпросмотр и подтверждение снимка, отказ при устаревшем предпросмотре. Уведомления только по явному выбору.
- Предпросмотр подготовленного DOCX/XLSX с аудиториями, руководителями, периодом и повторением; та же полная валидация, что при публикации, без сохранения.
- Композитор рассылок: аудитория, предпросмотр, время явно по Москве, история/отмена. Broadcast ID выделяется при отправке, чтобы старые Android-клиенты с курсором не пропускали запланированные сообщения. SQL-claim защищает от параллельной отправки. Неопределённый результат после сбоя не повторяется автоматически — честный статус вместо риска дубля.
- Статистика принятия транспортом/ошибок, анонимных показов и открытий (web/Android). Принятие транспортом не равно доставке; «показ» — передача Notification API, не доказательство прочтения. Подтверждения best effort, дедупликация по установке/рассылке/каналу/событию, сеть не блокирует показ/открытие.
- Настоящие XLSX и PDF с кириллицей, фильтр корпуса/аудитории, предпросмотр и печать. Строки Excel — literal inline strings, не формулы. ReportLab использует локальный Golos Text с OFL. Диапазон до 32 дней/5000 строк.
- Календарь: drag&drop одного вхождения с подтверждением даты/времени/аудитории, проверкой конфликтов и устаревания; на телефоне/клавиатуре та же операция кнопкой «Перенести». Проверен реальный drag→сохранение→Undo.
- Миграция 0016; старый набор триггеров 0013 зафиксирован, новые триггеры периода отдельно. Проверены upgrade/downgrade.
- Cache provenance: savedAt не теряется при invalidation; SW-offline учитывается даже при navigator.onLine=true. Доступные названия карточек содержат фазу занятия, но не спамят минутными обновлениями; ошибка лимита избранного доступна и без native toast.
- Дешёвая оптимизация запуска Android: повторная регистрация тех же notification channels не вызывает Binder каждый раз. Пользовательские настройки каналов сохранены.
