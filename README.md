# Расписание кружков колледжа

Веб-приложение для публикации расписания кружков и защищённого администрирования справочников, кружков, регулярных занятий и разовых исключений.

## Стек

- Python 3.10+ / FastAPI / SQLAlchemy 2 / Pydantic 2 / SQLite
- Frontend: HTML / CSS / JavaScript без npm и сборщиков

## Запуск из PowerShell

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.lock.txt
.\.venv\Scripts\python.exe server.py
```

Приложение будет доступно по адресу `http://127.0.0.1:8000/`, Swagger UI — `http://127.0.0.1:8000/docs`.

## Создание первого администратора

Регистрация в браузере отсутствует. Администраторы создаются вручную безопасной командой с интерактивным вводом пароля:

```powershell
.\.venv\Scripts\python.exe -m backend.scripts.create_admin --login admin
```

Если аргумент `--login` не передан, логин будет запрошен в консоли. Пароль никогда не передаётся через аргументы командной строки и хранится в базе только в виде `scrypt`-хеша.

## Что умеет админка

- вход и выход администратора по серверной cookie-сессии;
- просмотр, создание, редактирование и удаление направлений, руководителей, аудиторий, кружков и регулярных занятий;
- перевод кружка в неактивное состояние без удаления из базы;
- создание, редактирование и удаление отмен и переносов конкретных занятий;
- защита всех `/api/admin/*` маршрутов с ответом `401` без авторизации.

## Где лежат данные

- основная база данных: `development.sqlite3` в корне проекта;
- тестовая база для `pytest`: `test.sqlite3` в корне проекта;
- пример структуры данных: `data\sample-data.json`.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests -q
```

## Ограничения текущей версии

- `backend.scripts.seed` по-прежнему не реализован: начальные данные в рабочую БД нужно заносить через админку или напрямую через SQL;
- автоматическая проверка конфликтов расписания в административных маршрутах пока не выполняется, хотя структура данных для отмен и переносов уже поддерживается.
